# Portfolio
This repository contains my personal portfolio website.

It is built to showcase my engineering journey, selected projects, technical writing, and ways to connect with me.

* Present my work in a clean, professional format
* Show my growth from frontend engineering toward full-stack, cloud, and systems work
* Provide a single place for projects, writing, and contact links
