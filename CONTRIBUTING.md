# Contributing

Thanks for considering a contribution to the portfolio. This is a personal Next.js site that presents my engineering work, projects, and writing.

## Getting started

1. Read the [README](README.md) for the stack.
2. Content lives under `src/content/` (profile, projects, writing, and more).
3. Components live under `src/components/` and section layouts under `src/components/sections/`.

## Development rules

- **Run**: `npm run dev`
- **Build**: `npm run build`
- **Lint**: `npm run lint`
- Keep the responsive desktop/mobile behavior and accessibility intact.
- Keep project cards and live links accurate and current.
- Never commit `.env.local` or credentials.

## Commit and publishing

Leave commits and publishing to the repository owner. Ensure the project builds and lints before opening a pull request.
